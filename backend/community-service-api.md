# Community Service API Contract — Sprint 1

**Base URL:** `http://localhost:8081`  
**API prefix:** `/api/v1`  
**Authentication:** Deferred; Sprint 1 uses `demo-user-001`.  
**Database:** MySQL owned by Community Service.

## Design rules

- Angular calls the API entry point, not MySQL.
- The API exposes DTOs, not JPA entities.
- Posts own post content; comments belong to one post.
- `locationId` is optional. If supplied, it must reference an existing dummy location.
- Deleting a post also deletes its comments.
- `createdAt` and `updatedAt` are generated by the backend.
- Clients do not provide `id`, author identity, or timestamps.

## Posts

| Method | Path | Success | Purpose |
|---|---|---:|---|
| GET | `/api/v1/posts` | 200 | List posts. |
| GET | `/api/v1/posts/{postId}` | 200 | Read one post. |
| POST | `/api/v1/posts` | 201 | Create a post. |
| PUT | `/api/v1/posts/{postId}` | 200 | Update post content/location. |
| DELETE | `/api/v1/posts/{postId}` | 204 | Delete post and its comments. |

### Create/update request

```json
{
  "content": "A useful local recommendation",
  "locationId": 1
}
```

`locationId` may be `null`.

### Post response

```json
{
  "id": 1,
  "content": "A useful local recommendation",
  "authorId": "demo-user-001",
  "authorName": "Demo User",
  "locationId": 1,
  "createdAt": "2026-11-02T12:00:00Z",
  "updatedAt": "2026-11-02T12:00:00Z"
}
```

## Comments

| Method | Path | Success | Purpose |
|---|---|---:|---|
| GET | `/api/v1/posts/{postId}/comments` | 200 | List comments for a post. |
| GET | `/api/v1/posts/{postId}/comments/{commentId}` | 200 | Read one comment. |
| POST | `/api/v1/posts/{postId}/comments` | 201 | Create a comment. |
| PUT | `/api/v1/posts/{postId}/comments/{commentId}` | 200 | Update a comment. |
| DELETE | `/api/v1/posts/{postId}/comments/{commentId}` | 204 | Delete a comment. |

### Create/update request

```json
{
  "content": "This recommendation is useful."
}
```

### Comment response

```json
{
  "id": 10,
  "postId": 1,
  "content": "This recommendation is useful.",
  "authorId": "demo-user-001",
  "authorName": "Demo User",
  "createdAt": "2026-11-02T12:05:00Z",
  "updatedAt": "2026-11-02T12:05:00Z"
}
```

## Dummy locations

| Method | Path | Success | Purpose |
|---|---|---:|---|
| GET | `/api/v1/dummy-locations` | 200 | List seeded locations. |
| GET | `/api/v1/dummy-locations/{locationId}` | 200 | Read one location. |

The catalog is temporary. It is not the future Location & Matching Service.

## Error response

### Resource not found — 404

```json
{
  "timestamp": "2026-11-02T12:00:00Z",
  "status": 404,
  "code": "RESOURCE_NOT_FOUND",
  "message": "Post not found: 999",
  "path": "/api/v1/posts/999",
  "details": {}
}
```

### Validation error — 400

```json
{
  "timestamp": "2026-11-02T12:00:00Z",
  "status": 400,
  "code": "VALIDATION_ERROR",
  "message": "Request validation failed",
  "path": "/api/v1/posts",
  "details": {
    "content": "Content must not be blank"
  }
}
```
